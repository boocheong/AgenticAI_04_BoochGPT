# BoochGPT


# How to run BoochGPT
## 1. Clone the repository
   ``` bash
   git clone https://github.com/boocheong/AgenticAI_04_BoochGPT.git
   ```

## 2. Navigate to the project directory
   ``` bash
   cd BoochGPT
   ```

## 3. Create a vistual environment (optional but recommended):
   ``` bash
   conda create -n boochgpt python=3.11 -y
   ```

## 4. Activate the virtual environment:
   ``` bash
   conda activate boochgpt
   ```

## 5. Install the required dependencies
   ``` bash
   pip install -r requirements.txt
   ```

## 6. Run the application
   ``` bash
   python app.py
   ```
